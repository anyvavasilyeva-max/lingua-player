## Следующие шаги (согласованы, ещё не сделаны)

1. **«Ответ голосом» — следующий шаг, требует тестирования.**
   - По умолчанию **выключено**; включается переключателем в настройках воспроизведения.
   - На карточке — значок 🎤 (по аналогии с 👁): нажатие — ответить голосом на текущей карточке.
   - Распознавание: встроенный Android SpeechRecognizer (офлайн на Android 12–13+ при
     установленном языковом пакете), запасной вариант — Vosk (полностью офлайн).
   - Сравнение с правильным ответом после нормализации (для корейского — по чамо): ✓ / «почти» / ✗.
   - Разрешение `RECORD_AUDIO` запрашивается только при первом включении.
2. **После завершения всех этапов: пара по умолчанию — `en-US → ru-RU`** для всех новых
   установок (сейчас при первом запуске создаётся `ko-KR → ru-RU`). Существующие данные
   пользователей не меняются.
3. Версия для iOS — отдельный проект (см. ответ в истории разработки: SwiftUI + AVSpeechSynthesizer).
