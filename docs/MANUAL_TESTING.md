# Ручная проверка

Автоматические тесты (`./gradlew testDebugUnitTest`) запускаются на компьютере в Robolectric.
Они не заменяют проверку на настоящем телефоне — ниже то, что нужно пройти руками.


## Этап 2 — импорт и библиотека

1. **Импорт CSV из `samples/`.** Скопируйте `sample_ko_ru.csv` на телефон → Главная →
   «Импорт словаря» → «Выбрать файл». Ожидается: разделитель «Запятая», столбцы угаданы,
   тип взят из файла; предпросмотр — 8 найдено, 8 новых. После импорта в библиотеке 8 записей,
   `냄비` → «Кастрюля, котелок», `"괜찮아요"라고 했어요` с кавычками.
2. **Повторный импорт того же файла** с вариантом «Пропустить» → 8 пропущено, записей по-прежнему 8.
3. **«Обновить».** Отредактируйте в файле перевод `포크` и добавьте тег → импорт с «Обновить» →
   перевод заменён, старые теги на месте, новый добавлен. Если `포크` был в плейлисте — остался там.
4. **XLSX с двумя листами** (`sample_ko_ru.xlsx`): выберите лист «Фразы». Столбца типа нет —
   кнопка «Предпросмотр» неактивна, пока вы не выберете «фраза». Импортируется 3 записи;
   у `밥 먹었어요?` перевод «Ты поел? (приветствие)».
5. **Ваш файл на 3000+ слов.** Импорт идёт с индикатором прогресса, интерфейс не зависает.
   Если какие-то строки с ошибками — в отчёте есть их номера; исправьте их в Excel и
   импортируйте файл ещё раз с «Пропустить» — добавятся только исправленные.
6. **Excel «CSV (разделители — запятые)» на русской Windows** (кодировка Windows-1251):
   должно появиться предупреждение о кодировке. Для корейского используйте «CSV UTF-8».
7. **Старый `.xls`** → понятное сообщение «сохраните как .xlsx».
8. **Массовые действия**: долгое нажатие на запись → «Выбрать все» → «Добавить теги» →
   создать тег → «Сохранить». Тег появился у всех выбранных записей. «Снять теги» убирает его.
   «В плейлист» добавляет выбранные записи в обычный плейлист в порядке списка.
9. **Умный плейлист**: Плейлисты → «Новый плейлист» → «Умный» → «Фразы» + тег → «Сохранить».
   В нём только фразы с этим тегом. Добавьте тег ещё одной фразе — она появится сама.
10. **Тёмная тема**: включите в системе — все экраны читаемы.

## Этап 3 — плеер и голоса

1. **Голоса.** Настройки → «Голоса и озвучка». Для корейского и русского должно быть
   «работает без интернета». «Проверить» — звучит тестовая фраза на нужном языке.
2. **Нет корейского голоса.** Удалите корейские голосовые данные в системных настройках
   синтеза речи (или выберите движок без корейского) → «Обновить» → статус «не скачан» /
   «не поддерживается». Запустите плейлист: плеер остановится с сообщением «Нет голоса для
   языка „Корейский“» и кнопкой «Настройки голоса». Установите голос — всё работает.
3. **Без интернета.** Включите режим полёта → воспроизведение корейского и русского
   продолжается (если голоса офлайн). Если в «Голосах» было «только онлайн» — ожидаемо не звучит.
4. **Последовательность.** Плейлист с 3–4 словами, повторы 2, пауза 5 с: слово звучит дважды,
   5 с тишины, перевод, ~1 с, следующее слово. Фразы не накладываются.
5. **Направление.** «Русский → Корейский»: сначала перевод, затем корейский. «Случайно» —
   в разных записях по-разному; ⏮/⏭ туда-обратно сохраняют направление записи.
6. **Только слова / только фразы, перемешать.** Счётчик «N из M» меняется, текущая запись
   (если подходит под фильтр) остаётся текущей.
7. **Скорость.** Корейский 0,75×, русский 1,25× — разница слышна (если движок поддерживает).
8. **Без перевода.** Выключите «Произносить перевод» — звучит только корейский, перевод виден.
9. **«Не помню».** Нажмите на записи → кнопка меняет вид; в библиотеке у записи тег «#Не помню».
   Повторное нажатие снимает тег. Умный плейлист по тегу «Не помню» показывает трудные записи.
10. **⏸/▶, ⏮/⏭ во время речи** — фраза обрывается сразу, новая начинается без наложения.
11. **Мини-плеер.** Уйдите с экрана плеера — внизу полоска с текущим словом и ▶/⏸, ⏭.
12. **Известное ограничение этапа 3:** при выключенном экране или сворачивании приложения
    Android может остановить воспроизведение — это решается на этапе 4 (фоновый сервис).

## Версия 0.4 — карточки, повторы, оформление

1. **Скрытый ответ.** ⚙ → «Скрывать ответ на карточке». На паузе листайте карточки свайпом:
   ответ скрыт («• • •»), 👁 или нажатие на карточку открывает его; на следующей снова скрыт.
   При «Русский → Корейский» скрывается корейское слово.
2. **Зациклить список** (🔁 один раз): после последней записи — снова первая, ⏭ на последней
   переходит к первой. **Зациклить запись** (🔁 ещё раз): одна запись звучит по кругу до ⏭.
3. **Повтор с замедлением**: повторы 2, скорость 1× — второй раз заметно медленнее.
4. **Обложки**: плейлист → ⋮ → «Выбрать обложку» → картинка из галереи. Обложка видна в
   плитке, на главной и в плейлисте. «Убрать обложку» — снова название на цветном фоне.
5. **Цвет оформления**: выберите светло-жёлтый — кнопки и текст остаются читаемыми;
   проверьте и тёмную тему. «По умолчанию #00B2D1» возвращает исходный цвет.
6. **Обновление с версии 0.3**: установите поверх — все слова, теги и плейлисты на месте
   (миграция базы v1 → v2).

## Версия 0.5 — раздельные пары и «глазик»

1. Добавьте пару `en-US → ru-RU`, импортируйте в неё несколько английских слов, создайте плейлист.
2. На главной переключите пару чипом вверху: библиотека, плейлисты, недавние — только выбранной
   пары. Записей и плейлистов другой пары не видно; при переключении во время прослушивания
   плеер останавливается и очередь сбрасывается.
3. В плейлист корейской пары нельзя добавить английское слово (в редакторе записи видны только
   плейлисты её пары).
4. «Глазик»: короткое нажатие на 👁 скрывает ответ только на текущей карточке — на следующей он
   снова открыт. Удержание 👁 → «Ответ скрыт на всех карточках»: все следующие карточки скрыты,
   режим сохраняется после перезапуска. Удержание на скрытой → «Ответ открыт на всех карточках».
5. Обновление с 0.4: старые плейлисты остались, каждый попал в пару своих слов.

## Этап 4 — фон, экран блокировки, Bluetooth, звонки

Проверять на настоящем телефоне; лучше с плейлистом из 10+ записей, пауза 2 с.

1. **Заблокированный экран.** ▶ → кнопка питания. Воспроизведение идёт 5+ минут без остановок,
   паузы между словом и переводом не растягиваются. Включите экран (не разблокируя):
   на экране блокировки карточка с корейским текстом, переводом и ⏮ ▶/⏸ ⏭ — кнопки работают.
2. **Шторка уведомлений.** Карточка плеера; нажатие открывает экран плеера приложения.
   На паузе карточка остаётся; смахните — сервис закрывается.
3. **Bluetooth-наушники.** Подключите → ▶/⏸ на наушниках ставит/снимает паузу; «следующий
   трек» (двойное нажатие или кнопка) — следующая запись. Выключите наушники во время
   речи → пауза (речь НЕ должна зазвучать из динамика). То же с проводными наушниками.
4. **Входящий звонок** (позвоните себе с другого телефона). Речь останавливается при звонке,
   во время разговора не звучит, после завершения продолжается с начала текущей записи.
   Повторите, но во время звонка нажмите ⏸ в шторке — после звонка не продолжит.
5. **Другое приложение.** Включите музыку в другом плеере — Lingua Player встаёт на паузу.
   Голосовая подсказка навигатора — пауза и продолжение.
6. **Отключение интернета.** Режим полёта → всё продолжает работать (с офлайн-голосами).
7. **Отсутствующий корейский голос.** См. этап 3, п. 2 — сообщение и кнопка «Настройки голоса».
8. **Закрытие и повторное открытие.**
   a) Во время прослушивания смахните приложение из «Недавних» → продолжает играть
      (управление из шторки).
   b) На паузе на 15-й записи плейлиста, с перемешиванием → смахните приложение → откройте
      снова: мини-плеер показывает ту же запись, «15 из N», тот же порядок; ▶ продолжает.
   c) Перезагрузите телефон → откройте приложение → очередь и позиция на месте.
9. **Экономия батареи (Xiaomi, Huawei, Honor, Samsung).** Если при выключенном экране
   воспроизведение обрывается через несколько минут — снимите ограничения батареи для
   приложения и повторите п. 1.
10. **Android 13+:** уведомление-плеер появляется без запроса разрешения на уведомления.

## Этап 5 — экспорт и резервная копия

1. **Экспорт CSV/Excel.** Настройки → Данные → «Экспорт словаря в CSV» → сохраните в «Загрузки».
   Откройте в Excel/Google Таблицах: столбцы source, translation, type, tags; корейский читается.
   То же для XLSX. Плейлист → ⋮ → «Экспорт в Excel» — записи в порядке плейлиста.
2. **Обратный импорт.** Импортируйте экспортированный CSV в новую пару — записи совпадают.
3. **Резервная копия.** Настройки → Данные → «Создать резервную копию» → сохраните на Google Диск.
4. **Восстановление.** Удалите приложение (или установите на другой телефон) → установите →
   Настройки → Данные → «Восстановить» → выберите `.lpbackup` → подтверждение показывает
   количество пар/записей/плейлистов → «Заменить данные». Проверьте: все пары, записи, теги
   (включая переименованный «Не помню»), плейлисты в прежнем порядке, обложки, умные плейлисты,
   цвет оформления и настройки воспроизведения.
5. **Неверный файл.** Выберите при восстановлении CSV или картинку → «Это не резервная копия»,
   данные не изменились.
6. **Большой словарь.** 3000+ слов в каждой из 3 пар: переключение пар, поиск, открытие
   плейлиста, импорт — без заметных задержек; копия создаётся и восстанавливается за секунды.
7. **Release-APK** (если подписываете сами, см. docs/RELEASE.md): устанавливается и работает так же.
