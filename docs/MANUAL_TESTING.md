# Ручная проверка

Автоматические тесты (`./gradlew testDebugUnitTest`) запускаются на компьютере в Robolectric.
Они не заменяют проверку на настоящем телефоне — ниже то, что нужно пройти руками.
Разделы для плеера (экран блокировки, Bluetooth, звонки, офлайн-голоса) появятся на этапах 3–4.

## Этап 2 — импорт и библиотека

1. **Импорт CSV из `samples/`.** Скопируйте `sample_ko_ru.csv` на телефон → Главная →
   «Импорт словаря» → «Выбрать файл». Ожидается: разделитель «Запятая», столбцы угаданы,
   тип взят из файла; предпросмотр — 8 найдено, 8 новых. После импорта в библиотеке 8 записей,
   `냄비` → «Кастрюля, котелок», `"괜찮아요"라고 했어요` с кавычками.
2. **Повторный импорт того же файла** с вариантом «Пропустить» → 8 пропущено, записей по-прежнему 8.
3. **«Обновить».** Отредактируйте в файле перевод `포크` и добавьте тег → импорт с «Обновить» →
   перевод заменён, старые теги на месте, новый добавлен. Если `포크` был в плейлисте — остался там.
4. **XLSX с двумя листами** (`sample_ko_ru.xlsx`): выберите лист «Фразы». Столбца типа нет —
   кнопка «Предпросмотр» неактивна, пока вы не выберете «фраза». Импортируется 3 записи;
   у `밥 먹었어요?` перевод «Ты поел? (приветствие)».
5. **Ваш файл на 3000+ слов.** Импорт идёт с индикатором прогресса, интерфейс не зависает.
   Если какие-то строки с ошибками — в отчёте есть их номера; исправьте их в Excel и
   импортируйте файл ещё раз с «Пропустить» — добавятся только исправленные.
6. **Excel «CSV (разделители — запятые)» на русской Windows** (кодировка Windows-1251):
   должно появиться предупреждение о кодировке. Для корейского используйте «CSV UTF-8».
7. **Старый `.xls`** → понятное сообщение «сохраните как .xlsx».
8. **Массовые действия**: долгое нажатие на запись → «Выбрать все» → «Добавить теги» →
   создать тег → «Сохранить». Тег появился у всех выбранных записей. «Снять теги» убирает его.
   «В плейлист» добавляет выбранные записи в обычный плейлист в порядке списка.
9. **Умный плейлист**: Плейлисты → «Новый плейлист» → «Умный» → «Фразы» + тег → «Сохранить».
   В нём только фразы с этим тегом. Добавьте тег ещё одной фразе — она появится сама.
10. **Тёмная тема**: включите в системе — все экраны читаемы.
