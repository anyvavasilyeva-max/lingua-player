# Lingua Player

Аудиословарь, который работает как музыкальный плеер: загрузите свой словарь из Excel/CSV,
разложите слова по тегам и плейлистам и слушайте их с переводом — на прогулке, в дороге,
с выключенным экраном.

- Любые языковые пары (коды BCP 47). Первоначальный приоритет — корейский ↔ русский.
- Работает без интернета, без регистрации и без серверов. Все данные хранятся на телефоне.
- Озвучка — системный синтезатор речи Android (TextToSpeech).

> **Статус: этап 2 из 5 (библиотека).** Готовы: импорт CSV и XLSX, библиотека с поиском и
> фильтрами, редактирование записей, массовые действия (теги, плейлисты, удаление), теги
> (включая системный «Не помню»), обычные и умные плейлисты, языковые пары.
> **Ещё нет:** воспроизведения (этапы 3–4), экспорта и резервной копии (этап 5).

## Сборка

### Вариант А — Android Studio (рекомендуется новичкам)

1. Установите [Android Studio](https://developer.android.com/studio) (последнюю стабильную версию).
   Мастер первого запуска сам скачает Android SDK — соглашайтесь со всем по умолчанию.
2. Скачайте проект: **Code → Download ZIP** на GitHub и распакуйте (или `git clone`).
3. В Android Studio: **File → Open…** → выберите папку `lingua-player` → **OK**.
   Если спросит «Trust project?» — **Trust Project**.
4. Дождитесь окончания синхронизации Gradle (полоска внизу справа; первый раз — 5–15 минут,
   скачивается около 1 ГБ). Если Studio предложит установить недостающий SDK Platform 37 — нажмите
   ссылку **Install** в сообщении.
5. Подключите телефон:
   - На телефоне: **Настройки → О телефоне** → 7 раз нажмите **Номер сборки** → появится
     «Для разработчиков». Там включите **Отладка по USB**.
   - Подключите кабель, на телефоне разрешите отладку для этого компьютера.
6. Вверху Android Studio выберите свой телефон в списке устройств и нажмите зелёный ▶ **Run**.

Готовый APK для ручной установки: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**,
затем **locate** в уведомлении. Файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант Б — командная строка

Нужны JDK 17+ и Android SDK (путь в `local.properties`: `sdk.dir=/путь/к/sdk`
или переменная `ANDROID_HOME`).

```bash
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # автоматические тесты
./gradlew lintDebug            # статический анализ
```

### Установка APK на телефон без компьютера

Перекиньте `app-debug.apk` на телефон (через облако, мессенджер или кабель), откройте файл и
разрешите установку из этого источника. Android предупредит о неизвестном приложении — это
нормально для APK, собранного самостоятельно.

## Использование

- **Главная** — количество записей в активной языковой паре и недавно открытые плейлисты.
- **Импорт** — кнопка на главной или значок ⇪ в библиотеке. Шаги: выбор файла → лист Excel
  (если их несколько) → языковая пара → сопоставление столбцов → тип записей → что делать с
  дубликатами → предпросмотр → импорт → отчёт (найдено / новых / обновлено / пропущено / ошибок,
  список строк с ошибками и номерами строк).
- **Библиотека** — поиск (по слову и переводу, без учёта регистра), фильтры «Все/Слова/Фразы»
  и по тегам. Если выбрано ≥ 2 тегов, появляется переключатель «Любой из тегов / Все теги».
  Кнопка **Новая запись** — ручное добавление. Нажатие на запись — редактирование:
  слово, перевод (несколько вариантов через «;»), тип, теги, плейлисты, удаление.
- **Массовые действия** — долгое нажатие на запись включает режим выбора; дальше нажатия
  добавляют записи, кнопка ☐ выбирает все найденные (с учётом поиска и фильтров).
  Действия: добавить теги (можно сразу создать новый), снять теги, добавить в плейлист, удалить.
- **Плейлисты** — обычные (записи добавляются вручную, порядок: меню записи → «Выше / Ниже»)
  и **умные** (содержимое по условиям: языковая пара, слова/фразы, теги «любой»/«все»;
  новые подходящие записи попадают туда автоматически). Условия умного плейлиста меняются
  значком настроек на его экране. Удаление плейлиста не удаляет слова.
- **Теги** (значок метки в библиотеке или пункт в настройках) — создание, переименование,
  удаление. «Не помню» — системный тег: его можно переименовать, но нельзя удалить.
- **Настройки** — языковые пары: выбор активной, добавление новой (например, `ja-JP → ru-RU`).

## Формат файлов для импорта

Примеры: [`samples/sample_ko_ru.csv`](samples/sample_ko_ru.csv),
[`samples/sample_ko_ru.xlsx`](samples/sample_ko_ru.xlsx) (два листа с разными заголовками —
импорт позволяет сопоставить столбцы вручную).

| source | translation | type | tags |
|---|---|---|---|
| 포크 | Вилка | word | кухня;быт |
| 설거지를 하다 | Мыть посуду | phrase | кухня;TOPIK3 |

- Названия и порядок столбцов могут быть любыми. Приложение угадывает распространённые
  названия (`source`, «слово», «корейский», `translation`, «перевод», `tags`, «теги»…),
  остальное вы выбираете вручную.
- `type` необязателен. Понимаются `word`/`phrase`, «слово»/«фраза», `단어`/`문장` и т. п.
  Если столбца нет, тип для всех записей нужно выбрать явно — автоматически он не угадывается.
  Строка с неизвестным типом попадает в ошибки, остальные строки импортируются.
- `tags` необязателен, несколько тегов через `;`. Теги без учёта регистра: «Кухня» и
  «кухня» — один тег. Новые теги создаются автоматически.
- **CSV**: UTF-8 (с BOM или без), UTF-16 (Excel «Текст Юникод»). Разделитель `,`, `;` или
  табуляция определяется автоматически и меняется вручную. Значения с запятыми, кавычками и
  переносами строк должны быть в кавычках (Excel делает это сам). Если файл не в UTF-8,
  приложение прочитает его как Windows-1251 и предупредит — корейский текст в такой
  кодировке не сохраняется, поэтому в Excel выбирайте «CSV UTF-8».
- **XLSX**: любой лист; читаются значения ячеек (для формул — результат). Старый формат
  `.xls` не поддерживается — сохраните как `.xlsx`.
- **Дубликат** — запись с тем же словом (без учёта регистра и лишних пробелов) в той же
  языковой паре. Варианты: *пропустить*; *обновить* (перевод заменяется, тип — только если
  он есть в файле, теги объединяются, запись остаётся в своих плейлистах); *импортировать
  как новые*. Повторы внутри одного файла обрабатываются так же.
- Пустые строки игнорируются. Строки без слова или без перевода попадают в отчёт
  об ошибках с номером строки и не мешают остальным.
